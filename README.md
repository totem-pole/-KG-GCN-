## 2. 论文总体结构

### 摘要 / Abstract

围绕三条主线组织：

1. 汽轮机设备健康状态建模；
2. 汽轮机系统故障知识图谱构建；
3. KG-GCN故障诊断与VHP代表性算例。

### 第一章 绪论

- 1.1 研究背景及意义
- 1.2 燃煤机组汽轮机系统状态监测及故障诊断研究现状
  - 1.2.1 基于机理驱动的状态监测及故障诊断方法
  - 1.2.2 基于数据驱动的状态监测及故障诊断方法
- 1.3 现有研究与应用存在的问题
- 1.4 论文主要研究内容

### 第二章 基于GRU的燃煤机组汽轮机系统状态监测方法

按设备物理边界建立统一的 `U+B→Y` 状态监测范式，以VHP作为代表性工程对象比较ANN、TCN、iTransformer-small和GRU，并利用独立月份数据验证健康状态预测能力。

### 第三章 基于运行生产资料的汽轮机系统故障知识图谱构建

按照“系统参数及故障特性 → 运行生产资料 → 节点和关系定义 → LLM候选三元组 → 领域规则与Embedding校核 → 知识图谱结果”的顺序展开。

### 第四章 基于KG-GCN的燃煤机组汽轮机系统故障诊断方法

严格保持“图卷积网络 → KG-GCN模型输入构建 → Mask预训练与故障分类”的方法主线：

```text
健康状态模型
    ↓
多参数状态残差窗口
    +
知识图谱参数邻接
    ↓
GCN结构化特征聚合
    ↓
随机遮蔽重构预训练
    ↓
冻结GCN编码器
    ↓
FC + Softmax故障分类
```

### 第五章 故障诊断实验与结果分析

正文按杨昊东算例章节的功能顺序组织：

```text
研究对象及故障数据集
→ 实验设置与评价指标
→ CNN / AE / KG-GCN主结果表
→ 混淆矩阵
→ CNN误诊分析

→ KG-GCN优势分析
→ 小样本Mask预训练补充验证
```

### 第六章 总结与展望

- 6.1 论文主要工作
- 6.2 后续研究方向

## 3. 当前冻结的核心结果

### 3.1 VHP健康状态建模

- 训练：2024年5月正常运行DCS数据
- 独立测试：2024年6月
- 最终评价状态：24个
- 最终GRU结构：`24×16 → GRU(32) → LayerNorm → Dropout(0.05) → Linear(27)`
- 模型参数量：5755
- 最终24点宏平均R²：**0.9511**
- GRU在24个评价状态中的17个点取得四种模型最高R²

对比模型宏平均R²：

| 模型 | 宏平均R² |
|---|---:|
| ANN | 0.9087 |
| TCN | 0.9397 |
| iTransformer-small | 0.9356 |
| **GRU** | **0.9511** |

### 3.2 汽轮机系统故障知识图谱

当前审计口径：

- 标准实体：**127**
- 候选关系：**123**
- 进入主知识图谱：**121**
- 存在资料冲突、保留待核：**2**
- B级推断关系：独立保存，不进入主KG/GCN
- DCS映射：45条，其中44条已确认

主要实体类型包括：

- 设备
- 参数
- 异常
- 故障
- 状态概念

知识来源分为两类：

1. **机组特定事实**：DCS点表、设备IO、系统接口及建模审计资料；
2. **通用故障机理**：同行评议论文、标准和运行事件资料。

LLM只负责生成候选知识，不作为唯一证据来源。

### 3.3 VHP代表性KG-GCN诊断结果

3个随机种子正式汇总：

| 模型 | Accuracy | Macro-F1 |
|---|---:|---:|
| CNN | 98.33% ± 0.45% | 98.33% ± 0.45% |
| AE | 96.43% ± 0.82% | 96.43% ± 0.82% |
| **KG-GCN** | **98.45% ± 0.10%** | **98.46% ± 0.11%** |

固定seed=123主实验：

| 模型 | Accuracy | Precision | Recall | F1 |
|---|---:|---:|---:|---:|
| CNN | 97.86% | 97.89% | 97.86% | 97.85% |
| AE | 95.54% | 95.57% | 95.54% | 95.54% |
| **KG-GCN** | **98.57%** | **98.60%** | **98.57%** | **98.58%** |

### 3.4 Mask预训练小样本验证

分类阶段仅使用20%带标签故障窗口时：

| 方法 | Macro-F1 |
|---|---:|
| KG-GCN scratch | 94.48% ± 0.93% |
| **Mask预训练 + frozen encoder** | **96.67% ± 0.27%** |

提升：**+2.19个百分点**。

## 4. 数据与实验边界

### 健康状态数据

- 使用真实DCS健康运行数据训练状态监测模型；
- 2024-05训练，2024-06独立测试；
- 诊断阶段使用“DCS实测值 − 健康状态模型预测值”形成动态状态残差。

### 故障诊断数据

当前没有足够的现场真实故障样本，因此第五章主故障分类实验采用：

```text
真实健康运行残差背景
+
独立故障机理约束
+
时间演化与严重度扰动
=
半物理 / 机理一致故障场景
```

**禁止将该数据表述为真实电厂故障样本。**

故障空间签名不得直接由同一个KG邻接矩阵生成，避免循环验证。

## 5. 写作与研究硬约束

- 全文总体对象为**燃煤机组汽轮机热力系统**，VHP仅作为代表性算例。
- 健康状态建模统一采用设备物理边界 `U+B→Y`。
- 下游设备读取真实DCS边界值，不使用上游模型预测值级联。
- 第四、第五章技术路线和写作节奏以杨昊东KG-GCN章节为母版，但正文不得逐句仿写。
- 知识图谱不是RAG，不引入RAG路线。
- LLM只能用于候选知识抽取、标准化和辅助审核，不能成为唯一故障证据。
- 构造故障不得写成真实故障。
- 当前VHP结果不得外推为HP/IP/LP/凝汽器已经完成同等验证。
- 不为了获得更高结果修改测试标签、选择性删除难样本或隐瞒负结果。
