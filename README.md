## 写作原则

- 以汽轮机系统为总体研究对象，以超高压缸（VHP）为主要建模与实验示例。
- 健康模型采用当前稳定的 GRU 路线；其他模型仅作为对比基线。
- 知识图谱覆盖汽轮机本体及相关热力系统，不局限于 VHP。
- KG-GCN 方法继承课题组既有技术路线，但所有汽轮机对象、知识、数据组织和论文表述均重新构建。
- 文献优先引用原始论文、标准、厂家资料和高质量期刊来源；二手文献仅作为检索线索。
- 构造/仿真故障样本不得表述为真实电厂故障样本。
