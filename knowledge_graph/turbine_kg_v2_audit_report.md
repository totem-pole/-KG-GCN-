# 汽轮机系统故障知识图谱 v2 审计报告

## 核心原则
主知识图谱只允许 A0/A1 两类边：
- **A0**：本文机组设备台账、DCS测点和冻结IO直接确认；
- **A1**：同行评议原始论文、官方标准或官方运行事件直接支持；
- **A0\***：本文机组资料之间仍有冲突，保留候选但禁止进入GCN投影和论文主图；
- **B**：热力/大模型推断，仅用于半物理故障签名假设与鲁棒性分析，不进入主KG和主GCN邻接。

## 本机拓扑纠正
v2不再使用“HP→高压抽汽系统→高加组、IP→中压抽汽系统→除氧器、LP→低压抽汽系统→低加组”这种过度简化拓扑，而恢复本机已整理的真实抽汽关系：
1. VHP → 一级抽汽 → 1号高加；
2. HP → 二级抽汽 → 2号高加；
3. IP → 三级抽汽 → 3号高加；
4. IP → 四级抽汽 → 4号高加；
5. 五级抽汽 → 除氧器：最终114测点与早期设备台账存在描述冲突，标为A0*，暂不进入GCN；
6. LP → 六级抽汽 → 6号低加；
7. LP → 七级抽汽 → 7号低加；
8. LP → 八级抽汽 → 8号低加；
9. 五抽/七抽另有至BFPT小机供汽支路，仅系统KG保留，不进入当前VHP算例GCN。

## LLM + KG交叉审阅
大模型只负责候选实体/关系抽取、术语归一、冲突/重复提示和Schema类型检查。最终关系入图必须同时通过：
- 类型约束；
- 来源约束；
- 本机兼容性约束；
- 关系方向约束；
- 参数节点DCS可映射约束。

因此大模型知识不是唯一证据源。

## 对第五章实验的约束
半物理故障签名可参考B级热力推断，但KG-GCN主邻接默认只从A0本机结构/接口投影。A1故障机理用于第三章知识表达、第五章解释，以及后续单独的fault-aware KG扩展实验。这样避免用同一套知识同时生成故障数据和定义分类邻接造成循环论证。

## 当前高优先级待核冲突
`10LAA10CP101`在最终114测点体系中被描述为五级抽汽/除氧器压力，而早期设备台账出现“除氧器工质入口=四抽+凝结水”的描述。本版不强行裁决：该精确级次关系暂不进入GCN投影和论文主图。
