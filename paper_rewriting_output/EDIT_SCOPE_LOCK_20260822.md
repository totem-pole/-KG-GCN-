# 论文修改范围锁定（2026-08-22）

当前会议论文后续修改必须遵守以下范围约束：

1. **第一章/引言已由作者完成修改，禁止改写、删减、扩写或重排。**
2. 后续允许修改的正文范围仅为：**第2章及之后内容**，包括第2章状态监测、第3章KG-GCN方法、第4章算例分析及结论部分。
3. 不得因第2--4章新增实验而反向改写第一章的研究背景、国内外研究现状、研究动机或已有引用表述。
4. 若后续发现第一章存在参考文献编号、术语或数字与后文不一致，仅记录为“待作者确认项”，不得自动修改第一章。
5. 摘要、结论和第2--4章可根据冻结实验结果更新，但任何改动不得覆盖作者已经确认的第一章文本。

本约束优先于此前审稿Agent关于“全篇统一修改”的建议。后续所有审稿Agent和重构稿均应以此文件作为编辑边界。
