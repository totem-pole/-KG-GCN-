# 第五章实验规划 v1：KG-GCN汽轮机故障诊断

## 1. 规划原则
本实验方案按 PaperSpine 的 Results-as-Validation 和 reviewer-aware 原则组织：每一组实验必须回答一个明确的论文问题，而不是先跑模型再解释结果。

### 论文核心待验证论断
- **C1 健康残差有效性**：相较于直接使用原始DCS值，使用“实测值−健康状态模型预测值”的残差能够削弱正常工况迁移，使故障特征更稳定。
- **C2 知识拓扑有效性**：相较于无图结构或纯数据相关图，基于汽轮机知识图谱构建的参数拓扑能够减少无物理意义的特征混合，提高相似故障的区分能力。
- **C3 掩码预训练有效性**：大量无标签运行数据上的掩码残差预训练能够提高有限故障标签条件下的诊断性能与稳定性。
- **C4 完整KG-GCN有效性**：Residual + KG topology + masked pretraining 的完整方法在多类别故障诊断中取得最佳或具有竞争力的Accuracy / Macro-F1，并能给出与故障知识路径一致的参数解释。

---

## 2. 实验前必须完成的第一项：VHP故障可观测性审计
当前第二章最终诊断状态为24个VHP相关状态点。不能先随意指定5类故障再生成数据，而应先建立“候选故障 × 24状态节点”的可观测性矩阵。

### 每个单元格至少记录
- 预计响应方向：↑ / ↓ / 非单调 / 不确定；
- 机理证据来源；
- 故障到参数的知识传播路径；
- 响应时间尺度：快速 / 中等 / 慢变；
- 可观测等级：强 / 中 / 弱 / 不可观测；
- 是否与另一候选故障高度重叠。

### 第一批候选故障池（待审计后筛选，不等于最终类别）
1. 通流面积增大 / 固体颗粒侵蚀类；
2. 叶片沉积 / 通流面积减小类；
3. 汽封磨损或泄漏类；
4. 与一级抽汽支路相关的异常（只有在文献和24点可观测性支持后才保留）；
5. 调节阀死区/配汽异常（必须特别审查：若实际阀位已作为健康模型输入，故障影响可能被健康模型部分解释掉，未必适合作为VHP残差分类故障）。

### 筛选标准
最终优先保留3–5类满足以下条件的故障：
- 在24个状态节点上具有至少若干明确、可解释的响应；
- 不同故障之间具有可区分的空间/方向模式；
- 至少有独立机理文献或工程资料支持；
- 不依赖当前没有的机械振动/轴承专用信号；
- 能由后续故障样本构造方案实现。

## 3. 故障数据来源优先级
### Level A：真实确认故障窗口（最佳）
若后续能获得缺陷记录对应的真实DCS故障窗口，直接作为最终验证数据，并按故障事件而非滑窗随机拆分训练/测试。

### Level B：独立机理/仿真故障样本
若能够使用Dymola或独立热力模型生成故障响应，应先完成健康仿真与DCS测点的一致性校准，再将故障工况映射到同一24节点空间。故障生成模型与KG-GCN分类模型必须相互独立。

### Level C：半物理构造故障样本（当前最快可落地的proof-of-concept）
若短期内无法获得A/B级数据，可在真实健康残差窗口上叠加由独立机理证据定义的故障签名：

\[
R^{F}_{k,n}=R^{H}_{n}+a_n\,S_k\odot G_n+\epsilon_n,
\]

其中：
- $R^H_n$：真实健康残差窗口；
- $S_k$：第$k$类故障在24节点上的机理签名；
- $a_n$：随机故障严重程度；
- $G_n$：随时间发展的阶跃/渐变/缓升响应曲线；
- $\epsilon_n$：小幅随机扰动。

**论文中必须将该数据明确称为“构造故障场景/半物理故障样本”，不能写成真实现场故障样本。**

### 防止循环论证
故障签名$S_k$不能直接由KG-GCN使用的邻接矩阵生成，否则模型会被人为赋予与KG完全一致的数据模式。应采用独立的故障机理公式、原始文献参数方向、热力计算或另一套规则生成故障响应；KG只负责分类阶段的结构约束。

---

## 4. 数据划分与泄漏控制
1. GRU健康模型及StandardScaler只使用健康训练阶段数据拟合。
2. 残差标准化参数$\mu^H,\sigma^H$只由健康训练残差计算。
3. 若从真实健康残差构造故障样本，应先按连续时间块划分train/val/test，再分别构造故障，避免同一健康背景进入不同split。
4. 滑动窗口之间高度重叠，因此禁止对全部滑窗随机shuffle后再拆分；应先按事件/时间段拆分，再滑窗。
5. 若使用多严重程度故障，建议将部分严重程度或部分时间块作为外推测试，以验证对未见幅值的鲁棒性。
6. 所有模型使用相同split、相同故障样本、相同评价指标；模型选择只能看validation，不以test选超参数。

## 5. 实验组设计

### E1：完整方法与基线比较 —— 验证C4
建议主表只保留4–5个具有代表性的模型：
- MLP/ANN：无显式时序/图拓扑的基础分类器；
- 1D-CNN：与杨昊东论文保持一定可比性的时序局部特征基线；
- AE-based classifier 或 AE特征+分类器：与师兄路线对照，可视时间决定是否保留；
- Plain GCN：使用相同残差节点特征但不使用KG先验（可采用相关图或统一图定义）；
- **KG-GCN（本文）**。

主要指标：Accuracy、Macro-Precision、Macro-Recall、Macro-F1；必须给混淆矩阵和每类F1。

### E2：Raw vs Residual —— 验证C1
在相同分类网络和相同split下比较：
- Raw-GCN：使用原始状态值/标准化原始状态窗口；
- Residual-GCN：使用GRU健康残差窗口；
- Raw-KG-GCN；
- Residual-KG-GCN。

重点结果：不同负荷区间、升/降/稳态工况下的Macro-F1和误报/混淆变化。

### E3：知识拓扑消融 —— 验证C2
保持节点特征和GCN层数完全相同，仅替换邻接矩阵：
- $I$：仅self-loop，无节点间传播；
- Fully-connected（可选，仅作极端对照）；
- Corr-Graph：由健康训练数据相关性/互信息构图；
- **KG-Graph：知识图谱邻接**。

重点观察：相似故障类别之间的混淆是否因KG拓扑降低。

### E4：掩码预训练消融 —— 验证C3
- KG-GCN from scratch；
- KG-GCN + masked pretraining。

同时改变有标签训练数据比例：5%、10%、20%、50%、100%。
结果用Macro-F1均值±标准差（建议5个随机种子）和label fraction曲线呈现。

### E5：残差窗口长度敏感性
候选$L_r$由采样周期和故障时间尺度决定。初期可从若干离散长度中验证，例如10/20/30/60个采样点，但最终范围应根据故障响应持续时间确定，而非直接复制师兄的60。

### E6：鲁棒性实验
至少选择两类：
- 噪声鲁棒性：在测试集叠加不同幅值测量噪声；
- 故障严重程度：轻/中/重或连续幅值；
- 工况鲁棒性：低/中/高负荷，或稳态/升负荷/降负荷。

### E7：可解释性 / 故障传播结果
对正确诊断样本提取节点重要性（可使用节点激活幅值、梯度显著性或遮蔽敏感性），选Top-k异常参数并映射回第三章KG，展示：
故障实体 → 异常机理 → 高响应参数 → 系统接口。
重点不是追求复杂XAI，而是证明模型关注节点与已知热力故障路径相符。
