# 第二章写作迁移说明：杨昊东/吴婷婷 → 汽轮机GRU状态监测

## 1. 工程对象的写法
杨昊东工程对象不是简单列设备，而是按“结构与介质流程 → 参数类别 → 各参数表征的状态 → 为什么这些测点共同构成监测体系”展开。高压流化风机部分分别解释出口风温/风压、阀门指令/反馈、电机电流/定子温度、风机及电机轴承温度的物理意义，并与设备布置和空气流向对应。

### 本章迁移
汽轮机部分按以下顺序组织：
1. 汽轮机本体与主通流：主蒸汽→VHP→RH1→HP→RH2→IP→LP→凝汽器；
2. 再热系统：冷再/热再接口的作用；
3. 抽汽回热/给水：抽汽压力温度如何反映汽缸与加热器之间的能量接口；
4. 凝汽器/冷端：末级排汽、背压、循环水之间的耦合；
5. 状态监测变量角色：入口边界、操作量、设备本体、出口/接口、金属热状态。

## 2. 基础算法的写法
杨昊东介绍ITNN时依次写：算法类别/思想 → 网络结构 → 数据集数学定义 → 输入/隐藏/输出映射 → 与传统模型区别 → 目标函数 → 梯度更新。吴婷婷介绍RNN时也先定义时序数据集，再解释隐藏状态递归、前向公式、符号和回归损失。

### 本章迁移
GRU部分不能只给4个门控公式，应依次写：
1. RNN动态建模思想；
2. 时序训练样本定义；
3. RNN隐藏状态和输出映射；
4. RNN长期依赖问题；
5. GRU重置门/更新门/候选状态/隐藏状态；
6. 多变量时间窗口和多输出状态映射；
7. StandardScaler；
8. MSE目标函数；
9. BPTT与AdamW参数更新；
10. 本文真实网络24×16→GRU(32)→LN→Dropout→Linear(27)。

## 3. 本文模型构建的写法
基础GRU与“本文汽轮机状态监测模型”分开。GRU是算法原理；本文模型构建需要说明为什么按设备边界划分、B+U→Y、如何构造24点连续窗口、如何训练与选择模型，以及如何形成可推广至各设备的统一框架。

## 4. 工程算例的写法
工程算例单独成节，类似杨昊东3.5：
- 研究对象：VHP的物理位置、蒸汽过程、抽汽与再热接口；
- 测点：不只列点号，要解释每类点反映什么设备状态；
- 数据集及实验设置：2024-05训练、2024-06测试、数据清洗、24点窗口、模型参数；
- 结果：训练过程、总体指标、典型状态、模型对比、物理解释。

## 5. 证据边界
- 研究对象始终是燃煤机组汽轮机系统；VHP是工程应用代表性案例。
- 可写“该设备级框架可用于VHP/RH1/HP/RH2/IP/LP/CND等对象”，但没有结果文件时不声称全部对象已经取得具体精度。
- 真实模型Linear(27)；24点是预测完成后的最终评价/诊断节点口径。
- 不通过文字模糊或图形修改掩盖27→24关系。
