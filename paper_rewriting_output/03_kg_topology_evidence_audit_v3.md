# 第三章知识图谱拓扑与证据审计 v3

## 结论
当前自动生成的“汽轮机系统故障诊断知识图谱”图片不得进入论文。问题不是版式，而是部分设备—参数归属、抽汽支路和故障—参数边被过度概括或直接推断，尚未满足“机组真实DCS拓扑 + 独立故障证据”双重约束。

## 1. 图谱必须分成两类边
### A. 机组拓扑/测点边（最高优先级）
只能来自：
1. 用户机组DCS画面与点表；
2. 已冻结的设备IO表/边界关系；
3. 设备说明中能够与本机点号一一对应的接口。

文献中的通用汽轮机结构不能替代本机抽汽级次和加热器去向。

### B. 故障机理边
只能来自：
1. 同类汽轮机故障论文/标准/检修资料直接给出的因果关系；
2. 热力公式能够严格推出的关系；
3. 工程推断关系必须单独标为B级，不得与直接证据A混画成同一种实线边。

## 2. 当前能够确认的本机设备关系
### VHP
- 主蒸汽系统 → VHP：真实系统主通流关系。
- VHP → 一次再热/一次冷再接口：真实主通流关系；模型侧必须读取真实DCS接口，不用VHP预测级联。
- VHP → 一级抽汽系统 → 1号高压加热器：本机VHP审计中已有真实测点支持，包括一级抽汽口压力、1号高加入口抽汽压力、一级抽汽口/逆止门前后/高加入口多支温度。
- VHP本体状态包括叶片级压力、排汽压力/温度、缸体/内部蒸汽温度等。

### HP/IP/LP
当前v1知识图谱仅使用“HP→高压抽汽系统→高压加热器组”“IP→中压抽汽系统→除氧器”“LP→低压抽汽系统→低压加热器组”等通用关系。这些关系来自通用汽轮机文献，不足以作为本机最终图中的精确抽汽去向。

本机最终知识图必须恢复此前设备IO整理中的各级抽汽支路：HP、IP、LP均存在抽汽，且应明确对应到具体加热器/除氧器及真实DCS测点。未找到原始点表锚定前，不允许在最终图上写成“HP只有一个抽汽”“IP只去除氧器”“LP统一去低加组”。

## 3. 当前故障边的证据状态
### 可以直接保留（A级/较强）
- 高压调节阀死区 → 阀位对指令不敏感；并影响主蒸汽流量/可能诱发系统振荡。
- HP/IP/LP级间或轴端汽封缺陷 → 蒸汽泄漏。
- LP轴端密封异常 → 空气漏入低压/凝汽器侧 → 凝汽器真空下降。
- HP-IP中间汽封泄漏 → IP效率下降；与一次热再温度、IP排汽温度存在诊断关联。
- 固体颗粒侵蚀 → 首级喷嘴有效面积增大；可引起关键压力分布变化。
- 叶片表面沉积 → 通流面积减小 → 效率/出力下降；级前压力可异常升高。
- 凝汽器水侧污垢 → 换热能力下降；循环水温度/流量与凝汽压力共同相关；背压升高降低LP可用焓降。
- 给水加热器内部泄漏 → 回热性能下降；可与给水出口温度、抽汽侧压力等监测量关联。

### 不能直接画成确定边（当前生成图中存在的问题）
- “SPE → VHP叶片级压力下降/排汽温度升高”：现有证据支持的是通流面积和关键压力分布变化，但并未直接证明本机24个VHP测点的具体方向；应进入半物理故障签名的B级推断，不应作为KG确定边。
- “叶片沉积 → 某一支VHP叶片级压力/排汽温度”：同上，缺乏本机点级直接证据。
- “汽封泄漏 → 一级抽汽压力/温度、VHP排汽温度”：现有直接证据不足以支持这些具体点级连边；只可保留“汽封缺陷→蒸汽泄漏”等机理边，点级响应需独立热力推导或仿真证据。
- “调节阀异常 → 配汽偏差”：‘配汽偏差’不是当前证据库中已核验的实体，不能因绘图需要新造。
- “回热设备内漏 → 回热设备温度”：过于泛化，应换成具体加热器及真实可测参数。

## 4. 当前v1 schema错误
以下节点被错误标成“参数”，实际应为“异常/状态”：
- 凝汽器压力/背压升高；
- 凝汽器污垢热阻升高；
- 调节阀实际位置异常。

最终参数节点必须能够映射到实际DCS数值；“升高/下降/异常”属于语义异常节点，不能直接装载时序值。

## 5. 最终论文图的设计原则
最终图不再用图像生成模型直接生成关系。采用“审计后的edge table → SVG/draw.io自动布局”生成，保证每一根边都能回查来源。

建议图中仅保留三种视觉边：
- 灰色：本机设备拓扑/从属；
- 蓝色：真实DCS参数归属/接口；
- 橙色：有直接故障机理证据的故障传播边。

B级热力推断不进入主图，若必须展示则使用虚线并在图注说明“机理推断关系”。
