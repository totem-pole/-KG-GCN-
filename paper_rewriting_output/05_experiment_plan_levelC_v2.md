# 第五章实验规划 v2：Level C 半物理构造故障场景

## 1. 当前约束与论文口径

当前缺少可用于VHP热力故障分类的现场确认故障窗口，短期内也尚无可直接输出24个目标状态节点的独立热力仿真故障数据。因此，主实验暂采用 Level C：以真实健康DCS数据经GRU健康模型得到的真实残差窗口作为背景，在其上叠加由独立故障机理证据定义的故障响应，构建半物理故障场景。

该数据在论文中统一称为“半物理构造故障场景”“构造故障样本”或“机理约束故障场景”，不得称为现场真实故障样本。

## 2. 核心生成思想

设健康残差窗口为

R_n^H \in R^{N x L_r},

第k类故障的机理签名为

S_k \in R^{N},

则第n个故障样本定义为

R_{k,n}^F = R_n^H + a_{k,n} (S_k \odot G_{k,n}) + epsilon_{k,n}.

其中：
- R_n^H：真实健康运行背景中的残差窗口，保留真实DCS噪声、参数间正常相关性和GRU模型固有误差；
- S_k：第k类故障在24个状态节点上的空间响应签名；
- a_{k,n}：故障严重程度因子；
- G_{k,n}：故障随时间发展的动态包络，可为阶跃、缓升、渐变或饱和响应；
- epsilon_{k,n}：小幅独立扰动，用于避免同一故障类别形成完全固定模板。

## 3. 防止循环论证

故障签名 S_k 不由KG邻接矩阵生成。S_k 的方向、相对强弱和时间尺度必须来自独立来源：汽轮机热力机理公式、同行评议原始论文、设备运行/检修资料或独立热力计算。KG仅用于分类阶段限制GCN信息传播拓扑。

因此必须分别冻结：
1. Fault Signature Evidence Table：决定故障数据如何构造；
2. KG Adjacency：决定GCN如何聚合节点信息。

两者来源和生成规则相互独立。

## 4. 第一步：24节点故障可观测性矩阵

建立“候选故障 × 24状态节点”矩阵。每个单元格记录：
- 响应方向：+ / - / 0 / uncertain；
- 相对响应等级：strong / medium / weak；
- 时间尺度：fast / medium / slow；
- 是否存在延迟；
- 证据来源；
- 证据等级；
- 物理传播路径。

没有独立证据的单元格不得自行指定明显方向或强度。

## 5. 第一批候选故障

### F1 通流面积增大 / 固体颗粒侵蚀
重点观察级组压力、排汽压力/温度及相关接口状态。核心机理为有效通流面积改变导致级组压力分布和效率变化。

### F2 叶片沉积 / 通流面积减小
与F1形成相反或不同的空间压力响应模式，重点利用级组压力和排汽状态区分。

### F3 汽封磨损 / 蒸汽泄漏
重点观察与泄漏位置相关的级压力、排汽状态、抽汽接口及热再/IP相关状态。实际VHP 24节点可观测性需先审计。

### F4 配汽/调节阀异常（候选，不保证保留）
由于调节阀实际位置已作为GRU健康模型输入，部分阀位变化可能被健康模型解释。因此只有当独立测试证明输出残差仍存在稳定、可区分的异常模式时才纳入最终故障类别。

最终主实验优先保留3个最可观测、最可区分的故障类型，加正常状态F0；若F4可观测性充分，再扩展为4故障+正常。

## 6. 故障严重程度与时间形态

不使用单一固定幅值。每类故障至少设置连续严重程度区间，并在样本级随机采样。建议初始规范化严重程度因子 a ∈ [0.5, 2.0]，最终数值根据健康残差标准差和文献机理进行校准。

动态包络至少包含：
- abrupt：阶跃进入故障；
- ramp：线性/平滑缓升；
- gradual：慢变退化；
- partial-window：窗口中段开始故障。

不同故障的时间尺度应由机理决定，而不是所有故障统一使用同一曲线。

## 7. 真实健康背景的划分

先按照连续时间块将2024-06健康残差背景划分为train/validation/test候选池，再分别在各自背景池上生成故障样本。禁止先生成全部重叠滑窗再随机拆分，以避免同一健康背景或高度相似窗口跨集合泄漏。

测试集应使用与训练集不同的原始健康时间块，并可额外设置：
- 未见严重程度；
- 未见故障起始位置；
- 不同负荷区间；
- 升/降/稳态背景。

## 8. 数据生成质量检查

故障样本生成后先不训练KG-GCN，必须完成以下审计：
- 单节点残差分布是否仍处于工程可解释范围；
- 同类故障样本是否具有变化而非完全模板化；
- 不同故障类别是否存在合理重叠，避免人工制造完美可分数据；
- 正常与轻微故障是否存在真实困难区；
- PCA/UMAP仅用于可视化审计，不以其分离程度作为生成参数调优目标；
- 每类故障的Top响应节点是否与独立机理证据一致。

## 9. 必做实验

E1 主模型：MLP / 1D-CNN / Plain-GCN / KG-GCN。

E2 健康残差消融：Raw vs Residual，在相同分类网络和split下比较。

E3 KG拓扑消融：Identity / Corr-Graph / KG-Graph，仅改变邻接矩阵。

E4 掩码预训练消融：from scratch vs masked pretraining，并逐步降低故障标签比例。

E5 半物理构造鲁棒性：不同严重程度、不同时间包络、不同健康背景时间块。

## 10. 论文表述边界

允许表述：
- “在真实健康运行残差基础上构建机理约束故障场景”；
- “利用半物理构造故障样本验证方法在预定义热力故障场景下的诊断能力”；
- “实验用于验证KG-GCN方法链的可行性及各模块作用”。

不得表述：
- “采集了现场真实故障数据”；
- “模型已证明能够准确诊断真实电厂故障”；
- 将构造数据准确率直接外推为现场工程准确率。

## 11. 下一步执行顺序

1. 修正KG schema中“异常概念误标参数”的3个节点；
2. 冻结24个VHP诊断节点及真实DCS tag映射；
3. 建立候选故障 × 24节点可观测性矩阵；
4. 为F1-F4逐条收集独立机理证据并构建Fault Signature Evidence Table；
5. 先生成小规模样本进行分布和可观测性审计；
6. 冻结最终故障类别和严重程度范围；
7. 批量生成train/val/test半物理数据；
8. 运行E1-E5实验并回填第五章。
