# 第五章实验前置审计：2024-06健康残差分布与主实验切分协议 v1

## 1. 结论
2024-06整月GRU状态监测结果本身仍稳定，24个最终状态点的整月宏平均R²约为0.9511。此前Pilot中出现的“明显分布漂移”主要由临时采用的连续时间外推切分（如前半月训练背景、后半月测试背景）放大，而不是模型在整月范围内突然失效。

按6月前/中/后三段重新统计，24点宏平均R²约为：
- 前1/3月：0.9760
- 中1/3月：0.9462
- 后1/3月：0.9232

下降主要集中在少数温度状态，尤其是：
- 10MAA50CT111A 超高压内缸壁温90%处#1；
- 10MAA50CT121A 超高压排汽蒸汽温度#1；
- 10MAA50CT122A 超高压排汽蒸汽温度#2。

压力状态及大多数抽汽/冷再状态并未出现同等幅度的失效。因此更准确的表述应为“少数温度残差存在月内基线偏移/异方差”，不宜笼统称为全系统严重分布漂移。

## 2. 主实验切分协议（冻结）
主实验不采用连续的“前半月→后半月”时间外推切分，而采用覆盖整月、互斥自然日块的分层时间切分：
- 每5个自然日为一个时间组；
- 其中3天划入train、1天划入validation、1天划入test；
- 所有60点残差窗口必须完全位于单一自然日内部，不允许跨日或跨split；
- 残差标准化均值和标准差只由train日块的健康残差计算；
- 同一健康背景窗口及其故障构造版本只能属于一个split。

当前具体规则：日号 mod 5 ∈ {1,2,3} → train；mod 5 = 4 → validation；mod 5 = 0 → test。

使用train日块拟合残差标准化参数后：
- validation相对train的24维残差中心RMS距离约0.087σ；
- test相对train约0.113σ；
- 最大单点train-test均值偏移约0.32σ。

该差异明显小于此前连续前后月段切分所造成的偏移，适合作为主方法比较协议。

## 3. 严格时间外推的角色
连续时间外推切分不废弃，而改为后续鲁棒性实验：
- 训练：前段时间块；
- 测试：后段时间块；
- 用于考察模型对长期残差基线变化和未见工况背景的鲁棒性；
- 不作为KG-GCN主结果的唯一评估协议。

## 4. 对Level-C故障构造的影响
半物理故障样本仍采用真实健康残差背景：
R_fault = R_healthy + severity × signature × temporal_profile + noise。

关键要求：
1. 先划分健康时间块，再在各split内独立构造故障；
2. 不允许同一真实健康背景同时出现在训练和测试；
3. train/val/test使用一致的故障生成机制，但severity、temporal profile可在鲁棒性实验中设置未见范围；
4. 主实验采用上述整月分散日块协议，跨时间漂移另作为stress test。

## 5. 当前实验结论
漂移问题已从主实验协议中解除。下一步实验瓶颈不再是数据切分，而是：
- 24个DCS传感器与知识图谱“参数概念节点”之间如何映射；
- 当前三类故障签名是否具有足够独立且有机理依据的空间传播模式；
- KG邻接是否能够比Identity/Corr邻接提供额外价值。

因此下一步优先优化节点语义映射和故障签名，不通过改变split或人为增大故障幅值来追求更高准确率。
