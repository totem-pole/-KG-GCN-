# 第四章 Section Blueprint — KG-GCN汽轮机故障诊断

## 章节功能
把第二章的动态健康状态参考与第三章的静态汽轮机知识图谱融合为可训练的故障分类模型。本章只定义方法与训练流程；尚未完成的故障数据集、网络超参数和分类结果留到第五章。

## 主线
GRU健康模型 → 实测/预测残差 → 健康残差标准化 → 滑动残差窗口
+
汽轮机系统故障知识图谱 → DCS映射 → 参数关联子图 → 归一化邻接矩阵
→ KG-GCN → 无标签掩码预训练 → 少量故障标签分类 → 故障类别/异常节点/知识路径解释。

## 4.1 引言
- 解释向量模型缺少物理拓扑。
- 解释残差解决“工况变化 vs 设备异常”，KG解决“参数之间为什么相关”。
- 方法继承杨昊东KG-GCN骨架，但研究对象、参数图和健康模型均替换为汽轮机系统。

## 4.2 图卷积网络
### 4.2.1 图结构与邻接矩阵
- 语义KG是有向多关系图。
- 标准GCN输入使用参数层二值邻接图；语义方向与关系类型仍保留用于解释。
- 自连接、度矩阵、对称归一化。

### 4.2.2 GCN传播
\(H^{l+1}=\sigma(\bar A H^l W^l)\)。
- 一阶/高阶邻域与汽轮机热力传播关系对应。
- 不将GCN传播直接解释为严格物理因果证明。

### 4.2.3 图级特征与分类
- GAP → FC → Softmax。
- 交叉熵。
- 网络层数/hidden/C等参数待第五章验证，不虚构。

## 4.3 KG-GCN输入构建
### 4.3.1 全系统KG→参数子图
- 全系统KG不是只做VHP。
- 任务级子图从系统KG按DCS映射抽取。
- VHP后续算例可取最终24参数节点；扩展设备沿用同一规则。

### 4.3.2 健康残差
\(e_i(t)=y_i(t)-\hat y_i(t)\)。
\(r_i(t)=(e_i(t)-\mu_i^H)/(\sigma_i^H+\epsilon)\)。
- 健康统计量仅由训练健康数据拟合。
- 残差作为工况解耦接口，而不是直接把原始DCS输入GCN。

### 4.3.3 残差窗口
\(R_t\in\mathbb R^{N\times L_r}\)，行=参数节点，列=时间。
- 与GRU健康模型窗口区分，\(L_r\)为诊断模型超参数。

### 4.3.4 静态+动态融合
\(H^0=R_t\)，\(\bar A\)决定结构传播。

## 4.4 KG-GCN训练
### 4.4.1 无标签掩码预训练
- 随机mask残差窗口。
- GCN encoder + decoder恢复被遮蔽残差。
- loss只在mask位置计算。
- 参考杨昊东方法，并用GraphMAE作为一般自监督掩码图学习依据。

### 4.4.2 少样本分类
- 冻结预训练图编码器。
- labeled fault windows → encoder → GAP → FC/Softmax。
- CE loss。

### 4.4.3 推理解释
- 首要输出=故障类别概率。
- 辅助解释=高残差节点+设备归属+预测故障对应知识路径。
- 不把模型注意/GCN信息传播声称为因果识别。

## 4.5 小结
形成：健康建模 → 残差 → KG → GCN → 分类。
