# 会议论文审稿Agent第1轮：第2--4章结构与证据审计（2026-08-22）

## 0. 审稿目标

本轮只服务于《基于KG-GCN的燃煤机组汽轮机系统故障诊断方法》会议/小论文，不按硕士论文篇幅扩写。研究路线对齐杨昊东论文第四章的核心方法链：

> 运行生产资料 → 故障知识图谱 → 状态模型偏差映射 → 参数任务图 → GCN特征聚合 → 故障分类 → 算例验证。

但正文结构必须压缩为会议论文尺度，并以本项目真实汽轮机对象、DCS测点、训练协议和半物理故障实验为事实源。

---

## 1. 总体判断

### 当前最需要修正的不是“实验数量”，而是“章节证据结构”

新增实验已经使论文从“VHP单一区域验证”扩展为：

1. VHP：完整状态建模与四类故障基准；
2. H1/L6/BFPT/CND1：不同设备类型故障验证；
3. VHP--RH1：36节点跨设备系统扩展；
4. 8类高混淆任务：复杂类别压力测试；
5. 20%标签实验：掩码预训练有效性。

因此正文不能再延续“VHP主算例+其余均为未来工作”的旧叙事。

### 推荐会议论文最终结构

- 2 汽轮机系统状态监测模型
  - 2.1 汽轮机系统及设备级建模
  - 2.2 GRU状态监测模型及结果
- 3 基于KG-GCN的汽轮机系统故障诊断方法
  - 3.1 知识图谱与图卷积网络
  - 3.2 基于运行生产资料的知识图谱与任务参数图
  - 3.3 状态残差映射及KG-GCN训练
- 4 算例分析
  - 4.1 故障数据集与实验设置
  - 4.2 不同类型设备诊断结果
  - 4.3 系统扩展、高混淆与少标签实验
- 5 结论

这比把“知识图谱”“GCN方法”“故障实验”各拆成独立大章更适合会议论文，也与杨昊东第四章的完整链路一致。

## 2. 第2章审稿意见

### A类：必须修改

1. **删去硕士论文式算法展开。** 当前长稿中的“RNN长期依赖问题、BPTT、AdamW、ReduceLROnPlateau”等不应各自成为小节。会议论文只保留GRU门控公式、实际网络结构和必要训练协议。
2. **VHP仍可作为状态监测的详细代表对象，但不能写成唯一已验证设备。** 已有H1、DEA、CND1补充实验，应以一个紧凑表说明不同设备关键热力状态的可预测性及边界。
3. **必须明确状态监测与故障诊断接口。** 第2章结尾直接定义 `e_i(t)=y_i(t)-ŷ_i(t)`，说明完整残差窗口而非单点阈值进入KG-GCN。
4. **预测结果图改为论文级组合图。** 图2-7采用“完整序列+红框局部放大+散点分布”的杨昊东式信息结构，但使用本项目真实ANN/GRU预测数据。

### B类：建议修改

- 正文保留两类VHP代表测点：叶片级压力#1、超高压排汽蒸汽温度#3；一级抽汽温度进入结果表，不再单独占一张图。
- H1出口温度可作为非VHP稳健代表，但会议正文不再增加一整张H1预测图，避免第2章抢占故障诊断篇幅。
- 不采用“所有设备均达到R²>0.95”的表述。真实结果显示H1/DEA/CND1的液位、溶解氧和部分冷端状态明显更难建模。

### 第2章通过标准

- 2页左右正文；
- 3张核心图以内：系统原理图、VHP测点/输入输出图、GRU+预测组合图；
- 2--3张表：系统建模对象、四模型VHP结果、跨设备代表状态；
- 结尾能无歧义地过渡到KG-GCN残差节点输入。

## 3. 第3章审稿意见

### A类：必须修改

1. **KG和GCN先分开讲清楚，再组成KG-GCN。** KG负责静态工程知识与拓扑来源，GCN负责在任务参数图上传播数值特征，两者不能混写为同一算法。
2. **知识图谱构建按杨昊东路线压缩为一条连续链。** 数据源 → 候选三元组 → 类型/方向/设备兼容性审核 → Embedding实体对齐 → 主知识图谱 → 参数任务图。
3. **避免把LLM写成自动事实生成器。** 必须强调LLM仅生成候选关系，最终进入主图谱的关系需经结构资料、来源证据和人工/规则审核。
4. **把图谱统计数字保留。** 当前可审计知识库：127个标准实体、123条候选关系、121条进入主图谱、2条待核。这些数字比大段概念介绍更有工程说服力。

### B类：建议修改

- 表4“典型故障知识及主要关联区域”保留，但压缩文字说明。
- 图3建议只保留1张组合图：左侧KG构建流程，右侧系统级局部知识图谱；若版面不足，优先保留知识图谱局部图。
- GCN理论只保留自环、对称归一化和一层传播公式，不进行谱域推导。

### 第3章通过标准

- 2页左右；
- KG与GCN职责边界明确；
- 图谱来源和审核流程可追溯；
- 与第4章任务参数图和节点残差完全衔接。

## 4. 第4章审稿意见

### A类：必须修改

1. **取消“VHP代表性算例等于全文故障验证”的旧结构。** 新实验已覆盖高压加热器、低压加热器、给水泵小汽轮机和凝汽器，正文必须正式纳入。
2. **不得写“KG-GCN在所有设备上均优于CNN”。** 三随机种子结果中，CND1的CNN Macro-F1为98.21%±0.50%，高于KG-GCN的97.40%±0.76%。正确结论是：四类设备均达到95%以上，KG-GCN在H1、L6和BFPT取得最高均值，在CND1上并非最优。
3. **VHP--RH1系统扩展必须进正文。** 36节点、5类系统任务KG-GCN Macro-F1为94.789%±0.505%，证明从单设备走向跨设备任务时仍保持较高性能，但不能写“稳定超过95%”。
4. **8类高混淆实验必须进正文。** KG-GCN 68.299%±0.896%，CNN 54.163%±1.189%，AE 43.562%±0.997%；该实验比继续堆叠高精度单设备结果更能说明知识拓扑在复杂类别重叠时的价值。
5. **半物理边界必须保留。** 故障样本由真实健康残差背景叠加独立机理响应构造，不得写成现场真实故障事件。

### 推荐正文结果组织

#### 表A：不同类型设备三模型Macro-F1
- H1：KG-GCN 95.49±0.30，CNN 95.22±0.38，AE 94.83±0.64
- L6：KG-GCN 98.09±0.17，CNN 96.59±0.36，AE 95.90±0.36
- BFPT：KG-GCN 96.00±0.47，CNN 95.26±0.18，AE 94.64±1.05
- CND1：KG-GCN 97.40±0.76，CNN 98.21±0.50，AE 95.48±1.04

#### 表B：系统复杂度扩展
- VHP主任务：KG-GCN 98.46±0.11
- VHP--RH1 5类：KG-GCN 94.789±0.505
- VHP--RH1 8类高混淆：KG-GCN 68.299±0.896，CNN 54.163±1.189，AE 43.562±0.997
- 20%标签：Scratch 94.48±0.93 → Mask 96.67±0.27

### 第4章通过标准

- 3页左右；
- 至少同时覆盖本体、回热、给水/小机和冷端；
- 既报告高精度，也报告CND1基线反超和高混淆性能下降；
- 结论聚焦“系统适用性与复杂场景相对优势”，而不是绝对宣称KG拓扑始终最优。

## 5. 与杨昊东路线的一致与不同

### 一致

- 都是“状态参考/重构偏差 + 静态知识图谱 + GCN”的诊断链；
- 都从运行生产资料中构建领域KG；
- 都将连续运行偏差映射到参数节点；
- 都设置CNN、AE基线并通过混淆矩阵分析共享参数导致的误诊。

### 必须明确的不同

- 杨昊东状态监测对象为高压流化风机，本文为汽轮机设备级U+B→Y健康预测；
- 杨昊东故障实验为多系统五类真实/工程故障数据，本文现阶段为真实DCS健康残差背景上的机理半物理故障；
- 本文新增掩码预训练、节点身份保持式读出、跨设备36节点系统扩展与8类高混淆压力测试；
- 因此不能照抄其“工程真实故障验证”措辞，应坚持“方法链一致、对象和数据证据边界不同”。
