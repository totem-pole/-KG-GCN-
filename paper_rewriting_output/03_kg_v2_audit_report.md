# 汽轮机系统故障知识图谱 v2 审计报告

## 1. 证据分层
- **A0 本机事实层**：本文机组设备台账、DCS测点、冻结IO和系统边界能够直接确认的设备、参数与介质连接关系。
- **A1 外部直接证据层**：同行评议原始论文、ASME标准或官方运行事件报告直接支持的故障机理关系。
- **A0\***：本机资料之间存在尚未解决的冲突，保留候选关系，但禁止进入当前GCN投影与论文主图。
- **B 机理推断层**：热力学/大模型推断的点级响应关系，仅用于半物理故障签名假设、敏感性或鲁棒性分析，不进入主KG和主GCN邻接。

## 3. 本机抽汽拓扑纠正
v1中“HP→高压抽汽系统→高加组、IP→中压抽汽系统→除氧器、LP→低压抽汽系统→低加组”的通用化表示不再作为最终机组拓扑。v2根据已有设备IO和最终测点体系恢复为：
1. VHP → 一级抽汽 → 1号高加；
2. HP → 二级抽汽 → 2号高加；
3. IP → 三级抽汽 → 3号高加；
4. IP → 四级抽汽 → 4号高加；
5. LP → 六级抽汽 → 6号低加；
6. LP → 七级抽汽 → 7号低加；
7. LP → 八级抽汽 → 8号低加；
8. 设备台账另记录五抽/七抽至BFPT小机供汽支路。

五级抽汽/除氧器存在一个需要最终核对的资料冲突：最终114测点体系将10LAA10CP101描述为五级抽汽/除氧器压力，而早期设备台账出现“除氧器入口=四抽+凝结水”的文字。该关系当前标记为A0*，不进入GCN。

## 4. 典型A1故障知识
当前进入主KG的直接证据包括：
- 调节阀死区 → 阀位对指令不敏感 / 主蒸汽流量影响 / 系统振荡；
- HP、IP、LP级间或轴端汽封缺陷 → 蒸汽泄漏 → 汽耗增加；LP轴端密封异常还可导致空气漏入和凝汽器真空下降；
- HP-IP中间汽封泄漏 → IP效率下降，并与热再温度、IP排汽温度相关；
- 固体颗粒侵蚀 → 首级喷嘴有效面积增大；
- 叶片沉积 → 通流面积减小 → 出力/效率下降；
- 叶片表面粗糙度增大 → 通流损失增大；
- 凝汽器水侧污垢 → 换热能力下降 → 凝汽器背压受影响；
- 给水加热器内部泄漏 → 回热性能下降；
- ASME TDP-1将抽汽系统、给水加热器、疏水及防水倒灌作为汽轮机水损伤预防的重要对象；公开运行事件也证明抽汽逆止阀异常、抽汽管路冲蚀/泄漏可形成实际故障链。

## 5. LLM + KG交叉审阅
大模型仅承担候选关系抽取、同义词归一、冲突提示、节点类型检查和可疑因果边提示。关系只有在通过以下规则后才能进入A0/A1核心图：
1. 节点类型合法；
2. 关系方向符合Schema；
3. 有明确来源；
4. 外部文献机型与本文系统具有可说明的兼容范围；
5. 作为实时参数节点时能够映射实际DCS量；
6. 若文献只支持“故障→中间机理”，不得擅自延伸成“故障→本文某个具体DCS测点”。

## 6. 对第五章实验的约束
为避免循环论证，半物理故障签名与分类图拓扑分离：
- 主KG-GCN邻接优先使用A0本机结构/接口关系投影；
- A1故障知识用于故障解释和一个可单独报告的fault-aware KG扩展实验；
- B级点响应假设允许用于半物理样本生成，但不能同时作为主KG确定边。
