# 第二章 Section Blueprint v2

## 第二章总体任务
**章节功能**：为全文故障诊断建立可随运行边界变化的正常状态参考，不把第二章写成单纯的算法性能竞赛。

**研究对象边界**：燃煤机组汽轮机系统。VHP仅作为代表性对象完整展示“系统边界定义—测点选择—GRU建模—独立测试—模型比较”的全过程。

**章节主线**：
汽轮机系统热力拓扑 → 按物理边界划分设备对象 → B+U→Y统一建模范式 → GRU动态状态监测 → VHP代表性算例 → 独立月度验证 → 为后续KG-GCN提供健康状态参考。

## 2.1 引言
**功能**：解释为什么故障诊断前必须先建立状态监测/健康参考。

**核心claim**：宽负荷条件下汽轮机测点正常取值随主汽边界、负荷和阀门状态变化，固定阈值难以区分工况迁移与设备异常，因此需要条件化状态监测模型。

**证据锚点**：Dettori2017MonitoringModels；Cao2016LastStageNormalValue；Li2021LSTMStageWarning；Chen2023AdaptiveTransfer；用户DCS建模事实。

**段落结构**：工程问题 → 状态监测在故障诊断链路中的角色 → 为什么采用设备级建模 → 为什么选择GRU并设置ANN/TCN/iTransformer-small对比。

## 2.3 基于GRU的状态监测模型

### 2.3.1 GRU基本原理
**功能**：只介绍与本文动态建模直接相关的门控机制，不写成神经网络教科书。

**内容**：RNN时序特征 → GRU更新门/重置门 → 候选隐藏状态 → 当前隐藏状态。

**引用**：Cho2014GRU。

### 2.3.2 GRU状态监测模型结构
**真实结构**：24×16 → 单层GRU(32) → LayerNorm → Dropout(0.05) → Linear(27)，参数量5755。

**重要口径**：27为真实训练输出；最终24点是在预测后剔除CT132A、CT151A、CT152A形成，不能把代码写成Linear(24)。

**图件**：[图2-4] GRU网络结构图，正文只详细绘制GRU；ANN/TCN/iTransformer-small作为对比模型在表格和文字中交代。

### 2.3.3 数据标准化与模型训练
**内容**：StandardScaler仅由训练数据拟合；标准化MSE；AdamW；ReduceLROnPlateau；梯度裁剪；训练月内部按时间划分训练/验证，最佳epoch后完整训练月重训。

**关键证据**：selection_loss.csv和full_train_loss.csv。

### 2.3.4 对比模型设置
**模型**：ANN静态基线；TCN卷积时序基线；iTransformer-small注意力时序基线。

**审稿边界**：ANN不具有与时序模型相同的历史信息，因此正文明确其作用是“无显式时间历史的静态基线”，不声称四模型输入张量完全相同。

## 2.5 算例分析与模型对比

### 2.5.1 模型训练过程
**证据**：selection_loss.csv共191轮；最佳val MSE=0.057533@epoch161，train MSE=0.043519；完整训练月重训epoch161时full_train_loss=0.039283。

**图件**：[图2-5] 训练/验证损失和最佳epoch。

### 2.5.2 总体状态监测性能
**核心结果**：24点测试宏平均R2：ANN 0.9087，TCN 0.9397，iTransformer-small 0.9356，GRU 0.9511。

**图表**：[图2-6] 四模型宏平均R2；[表2-4] 总体性能；[表2-5] GRU四状态组性能。

**GRU分组**：Y1=0.9581，Y2=0.9634，Y3=0.9569，Y4=0.8893。

### 2.5.3 典型状态参数预测结果
**Figure contract原则**：不只挑最好结果，覆盖四类不同物理难度。

**代表点**：叶片级压力#1（R2=0.9979）；排汽蒸汽温度#3（0.9387）；一级抽汽逆止门后管顶温度（0.9529）；内缸壁温90%处#1（0.7346）。

**图件**：[图2-7] 统一测试集前48 h的四panel曲线；R2仍按完整测试月计算。

### 2.5.4 不同模型对比与结果讨论
**核心claim**：GRU在17/24点取得最高R2，但不是所有点均最优；其价值在于总体状态覆盖、动态温度与接口状态性能以及较小模型规模。

**讨论重点**：压力点易预测；排汽/抽汽温度更能体现时间信息价值；缸体温度暴露较强热惯性和未显式边界，是模型限制而非应删除的“不好看结果”。

**章节落点**：第二章只证明GRU可作为健康状态参考；残差的正式定义、标准化及滑动窗口留到第四章“KG-GCN模型输入构建”。
