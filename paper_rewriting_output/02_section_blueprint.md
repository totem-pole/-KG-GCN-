# 第二章 Section Blueprint v3（杨昊东式完整章节）

## 第二章总体任务
**章节功能**：建立燃煤机组汽轮机系统的健康状态参考模型，为后续KG-GCN故障诊断提供动态状态基准。

**结构迁移原则**：参考杨昊东第二/三章的“工程机理或基础对象 → 基础算法 → 本文模型构建 → 工程算例 → 小结”节奏，而不是将系统介绍、算法、实验压缩在同一个短章节。

**研究对象边界**：全文研究对象为燃煤机组汽轮机系统。VHP仅作为代表性工程算例完整展示输入输出定义、网络训练及状态监测效果。

**主线**：汽轮机热力系统机理与参数角色 → RNN/GRU理论 → 设备级B+U→Y建模框架 → VHP工程算例 → 2024-05/06独立验证 → 健康状态参考 → 后续KG-GCN。

## 2.1 引言
- 工程问题：宽负荷下正常参数分布发生变化，固定阈值容易混淆工况与异常。
- 状态监测定位：学习给定边界下的健康状态，而不是单纯追求预测精度。
- 系统级建模动机：汽轮机由多个具有明确物理边界的子设备组成。
- 方法选择：GRU为主模型；ANN、TCN、iTransformer-small作为基线。

## 2.2 燃煤机组汽轮机系统运行机理及状态参数
### 2.2.1 汽轮机本体及主通流过程
主蒸汽→VHP→RH1→HP→RH2→IP→LP→凝汽器；解释主汽边界、调节阀、级压力、排汽状态及上下游接口的物理意义。

### 2.2.2 再热系统
解释冷再/热再在不同汽缸之间的边界作用，说明RH1/RH2为什么作为独立热力对象保留。

### 2.2.3 抽汽回热及给水系统
解释抽汽压力/温度同时表征汽缸状态和加热器蒸汽侧入口；介绍高低加、除氧器、给水泵的能量联系。

### 2.2.4 凝汽器及冷端系统
解释末级排汽、背压、循环水和真空系统之间的耦合，说明LP与CND边界。

### 2.2.5 状态参数及建模边界
将参数分为直接热力边界、操作量、本体状态、热力接口状态、慢变金属热状态；用表说明每类参数反映的物理过程。

**证据**：LiPing2018SteamTurbine、Zhang2018AllCondition、用户DCS/测点资料。

## 2.3 GRU模型
### 2.3.1 RNN时序建模原理
训练集数学定义、隐藏状态递归、输出映射、符号说明、长期依赖问题。

### 2.3.2 GRU网络及门控机制
重置门、更新门、候选状态、隐藏状态四组公式；逐项解释门控含义及其对汽轮机快/慢动态的适用性。

### 2.3.3 多变量时序样本与多输出映射
定义L×m时序输入；最后隐藏状态→q维多状态输出；解释共享动态特征为何适合设备级多测点建模。

### 2.3.4 数据标准化与回归损失
StandardScaler训练数据拟合；MSE目标；反标准化后评价。

### 2.3.5 BPTT与参数优化
BPTT、AdamW、ReduceLROnPlateau、梯度裁剪。

## 2.4 基于GRU的汽轮机系统状态监测模型构建
### 2.4.1 设备级输入输出构建原则
B+U→Y；不使用本级近出口强相关量作为输入；不级联模型预测；保留接口状态。

### 2.4.2 时序样本构建
时间戳对齐、连续窗口、训练/验证时间划分、StandardScaler。

### 2.4.3 本文GRU网络
真实结构24×16→GRU(32)→LayerNorm→Dropout(0.05)→Linear(27)，5755参数；27≠24。

### 2.4.4 对比模型
ANN静态基线；TCN卷积时序基线；iTransformer-small注意力时序基线。

## 2.5 工程应用算例
### 2.5.1 研究对象
VHP的入口主蒸汽、汽缸通流、一级抽汽、冷再接口；解释为何具有代表性。

### 2.5.2 输入输出及测点
16输入；27候选输出；删除CT132A/CT151A/CT152A后24最终状态；Y1–Y4物理分组。

### 2.5.3 数据集及预处理
2024-05训练、2024-06测试；1 min；43911/42710有效记录；24点窗口；不纳入高旁主模式。

### 2.5.4 实验设置及指标
真实训练超参数；R2/RMSE/MAE；不跨单位宏平均RMSE/MAE。

### 2.5.5 训练过程
selection_loss：best epoch 161，val 0.057533；full_train epoch161 0.039283。

### 2.5.6 状态监测结果及模型对比
宏R2：ANN 0.9087 / TCN 0.9397 / iTransformer 0.9356 / GRU 0.9511；GRU 17/24最优；分组与典型点分析；保留低精度金属温度作为模型边界。
