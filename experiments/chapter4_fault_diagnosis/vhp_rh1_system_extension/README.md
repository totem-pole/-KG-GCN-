# Level-C v10：VHP--RH1系统级共享参数故障实验

## 定位

本实验扩展VHP单设备算例，使用2024年6月对齐的VHP 24节点与RH1 12节点真实健康残差，构建36节点系统级半物理故障任务。故障空间签名独立配置，不读取KG邻接矩阵。

## 分层任务

1. **冻结VHP主算例**：论文正式98.46% Macro-F1结果保持不变；
2. **5类系统名义扩展**：正常+4类跨设备故障，2--3 sigma，10%幅值扰动，无活跃节点删除；
3. **8类共享参数压力测试**：正常+7类故障/拓扑异常，故障签名最高100%节点重合；
4. **OOD/弱故障**：未见Step形态、0.25--0.7 sigma弱严重度。

## 关键结果

- 8类高混淆任务，3-seed KG-GCN Macro-F1：0.68299±0.00896；CNN：0.54163±0.01189；AE：0.43562±0.00997；
- 5类系统名义扩展，5-seed KG-GCN IID：Accuracy 0.94743±0.00519，Macro-Precision 0.94922±0.00476，Macro-Recall 0.94743±0.00519，Macro-F1 0.94789±0.00505；
- 5类系统扩展接近但未稳定超过95%，不能替换冻结VHP主结果；
- 标签打乱Accuracy约13.1%，接近8类随机水平12.5%；
- Train/Val/Test无日期交集、无精确重复窗口。

## 诚信边界

- 不保证KG在所有种子、所有图消融和所有OOD场景均优于Identity/Corr；
- 系统扩展是半物理故障，不是现场真实故障；
- 低严重度与未见时间形态性能显著下降，必须报告；
- 不按测试结果继续修改故障签名或删除困难类别。

- `audit_system_dataset.py`：重复窗口和日期泄漏审计；
