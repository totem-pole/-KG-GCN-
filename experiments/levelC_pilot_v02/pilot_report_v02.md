# Level-C 半物理故障实验 Pilot v0.2

## 1. 目的
本轮不把结果作为论文最终性能，而用于回答两个实验设计问题：

1. 24个DCS传感器是否应直接等同于24个知识图谱参数节点；
2. 在13个语义参数概念节点上，杨昊东式“GCN + Global Average Pooling”是否能够保留VHP局部故障的空间位置特征。

## 2. 数据
- 健康背景：2024-06真实 `DCS实测值-GRU预测值` 残差；
- 原始状态点：24；
- 映射后语义参数概念：13；
- 时间窗口：60；
- Train / Val / Test：按自然日块互斥划分，任何窗口均不跨日、不跨split；
- Train=1712, Val=556, Test=560，四类严格平衡。

## 3. Pilot故障
- F0：正常；
- F1：SPE / 通流有效面积增大；
- F2：汽封泄漏 / 效率退化；
- F3：一级抽汽阀或NRV堵塞/无流。

故障签名仍分A/B/C证据等级，C级节点不参与v0.2注入。

## 5. 关键发现
- MLP能够明显高于随机水平，说明v0.2故障场景具有可学习信息，但没有被设计成接近100%的一眼可分模板。
- 标准GCN + GAP仍明显低于MLP，且KG邻接没有优于Identity/Corr图。
- 仅用于诊断的“GCN后保留节点位置再分类”版本明显恢复性能，说明主要瓶颈不是数据不可分，而是标准GAP对局部节点位置的丢失与图平滑。
- 因此目前不能把标准KG-GCN Pilot结果写成论文主结果，也不能通过提高故障幅值强行让KG-GCN获胜。

## 6. 下一步
1. 继续保持师兄方法作为主基线；
2. 用更物理的故障生成方式替代固定sigma签名，尤其F1采用Stodola/通流面积扰动；
3. 对F3一级抽汽阀/NRV堵塞补入第三章KG并明确“阀前—阀后—高加入口”传播链；
4. 评估两条路线：
   - Route A：保持标准GCN+GAP，仅优化知识子图投影/故障场景，不改变算法；
   - Route B：若Route A仍失败，再考虑最小汽轮机适配（保留节点位置信息的池化或节点标识），并将其作为明确的方法改进而非暗改师兄算法。
5. 标准GCN结构稳定后再开展masked pretraining消融。

## 7. 诚信边界
本轮全部故障数据均为真实健康残差背景上的半物理构造场景，不是现场真实故障。`Diagnostic-KG-GCN-noGAP`仅用于定位结构问题，不属于当前论文主方法。
