# Chapter 2 — device health reference models

Chapter 2 establishes normal-condition state estimates and converts engineering residuals into the node signals consumed by the fault-diagnosis graph.

The paper-facing evidence is intentionally compact:

1. VHP retains the complete four-model comparison and final 24-state reporting convention.
2. H1 and deaerator provide successful non-VHP thermodynamic-state examples.
3. CND1 is retained as a negative/boundary case rather than hidden.
4. All predictions are stored in engineering units; test data never refit a scaler.

See each subdirectory for the exact input/output definitions, time split, metrics and integrity notes.
