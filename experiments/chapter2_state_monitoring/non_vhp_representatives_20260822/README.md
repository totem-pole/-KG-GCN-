# 第二章多设备快速补充实验

## 设备与协议

- 设备：DEA除氧器、H1高加1、CND1凝汽器1；
- 2024年5月训练/验证，2024年6月独立测试；
- 1 min采样，24 min窗口；
- ANN、GRU、TCN、iTransformer-small；
- DEA/H1采用3个随机种子；CND1完成首轮审计；
- 指标：R²、RMSE、MAE、Bias、物理容差合格率、残差自相关。

## 可进入第二章的代表点

- DEA压力1/2：GRU三种子R²约0.973/0.972；
- H1出口给水温度：0.99771±0.00023；
- H1压力：0.99749±0.00082；
- H1疏水温度：0.99701±0.00080。

以上点均满足GRU R²≥0.95且三种子均值高于ANN、TCN和iTransformer-small。

## 不能隐藏的结果

- DEA液位/溶解氧未达标，导致全部Y宏平均较低；
- H1三路水位R²仅约0.44--0.54；
- CND1本轮所有点均未达0.95，不进入代表图；
- 代表点只说明核心热力状态可形成健康参考，不代表整设备所有输出均超过0.95。
