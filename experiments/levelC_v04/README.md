# Level-C VHP KG-GCN Experiment v04

> 研究对象仍为燃煤机组汽轮机系统；本目录仅保存论文第五章中 **VHP代表性算例** 的半物理故障诊断实验。

## 当前状态（2026-08-19）

本目录用于保存从 v03 Pilot 继续发展的 v04 实验代码与结果。当前结果已经证明整个流程可运行，但**精度尚未达到论文最终要求**，因此以下结果全部标记为 development / pilot，不得直接作为最终论文定稿数字。

## 最终方法路线锁定

后续论文的故障诊断技术路线与杨昊东论文第四章保持一一对应的研究结构，不再因为Pilot模型效果而更换主方法：

1. 由运行生产资料、设备结构、DCS测点和故障资料构建汽轮机系统故障知识图谱；
2. 由第二章健康状态监测模型得到实测状态与健康预测之间的残差；
3. 对残差进行标准化并构造滑动残差窗口矩阵；
4. 将残差窗口按参数/DCS映射装载到知识图谱参数节点；
5. 由知识图谱投影得到图邻接关系，利用GCN完成逐层邻域特征聚合；
6. 在大量无故障/无标签残差窗口上执行Masked residual reconstruction预训练；
7. 采用预训练后的GCN编码器进行少样本故障分类训练；
8. 使用Accuracy、Precision、Recall、F1、Macro-F1和混淆矩阵进行对比评价；
9. 与AE、CNN等基线比较，并从共享参数、故障传播路径和混淆类别解释KG-GCN优势。

**硬约束：最终论文主方法仍表述为“知识图谱 + GCN + 掩码预训练 + 故障分类”，不引入TCN/GRU/Transformer作为KG-GCN主干来改变技术路线。** 可以优化节点输入映射、GCN层数/维度、残差连接、归一化、mask策略、预训练/微调方式与训练超参数，但不得改变上述主链。

**结果目标：当前0.8958 Macro-F1仅为开发阶段结果，继续优化至高精度区间。** 允许基于训练/验证集进行结构与超参数选择，但测试集固定，不允许事后修改标签、删除难样本、依据测试结果调故障幅值或直接修改指标。

### 固定数据协议
- 健康背景：2024-06 真实 DCS 实测值与第二章 GRU 健康模型预测值之差；
- 诊断节点：VHP 最终 24 个状态测点；
- 窗口长度：60 min；
- 类别：F0 正常、F1 VHP通流侵蚀/SPE、F2 一级抽汽逆止门后管路泄漏、F3 VHP汽封泄漏；
- 数据来源：真实健康残差背景 + 独立机理约束的半物理故障签名；
- Split：按自然日互斥，每5天中1--3日train、第4日validation、第5日test；窗口禁止跨日和跨split；
- Train / Val / Test：1712 / 556 / 560 windows，4类平衡；
- 指标：Accuracy、Macro-Precision、Macro-Recall、Macro-F1、混淆矩阵，与杨昊东KG-GCN算例保持一致。

## v04 已完成的关键修正

### 1. KG邻接不再由故障签名反推
当前 KG 图只根据 A0 级本机设备IO、真实DCS位置和直接热力接口生成，避免用同一套故障知识同时“造数据”和“定义邻接”导致循环论证。

### 2. 24个固定DCS节点保留节点身份
早期 `GCN -> Global Mean Pooling` 会把“哪个物理节点异常”平均掉。v04 改为 node-aware readout：GCN后保留24节点次序，再进入分类器。

### 3. 有序传感器拓扑
目前主要物理边包括：
- VHP叶片级压力#1 -> #2 -> #3；
- 叶片级末端 -> A/B排汽垂直管；
- 排汽区域 -> RH1一次冷再接口；
- 一级抽汽口 -> 逆止门前 -> 逆止门后 -> 1号高加入口；
- 缸壁温/内部蒸汽温度作为慢热状态支路。

## 当前5-seed结果（development）

| Model | Accuracy | Macro-F1 |
|---|---:|---:|
| AE | 0.3300 ± 0.0135 | 0.2988 ± 0.0308 |
| CNN | 0.7268 ± 0.0169 | 0.7278 ± 0.0172 |
| Identity-Sensor | 0.8904 ± 0.0179 | 0.8912 ± 0.0175 |
| Corr-Sensor | 0.8886 ± 0.0136 | 0.8892 ± 0.0136 |
| **KG-OrderedSensor** | **0.8950 ± 0.0053** | **0.8958 ± 0.0055** |

当前结果方向已满足 `KG-GCN > CNN > AE`，但绝对精度仍未达到论文最终目标；尤其 KG 相对 Identity/Corr 的提升仍小，因此不能把本轮数字写成最终结论。

## 当前瓶颈
1. GCN节点输入编码与图传播能力仍偏弱；
2. F1/F3均作用于VHP本体和排汽区域，故障空间签名存在较强重叠；
3. 当前Masked pretraining + frozen encoder没有取得正收益，说明预训练任务与分类任务尚未充分对齐；
4. 当前KG仅使用A0直接拓扑，尚需测试在不引入循环论证的前提下，如何利用审计后的A1故障传播知识改善图表示；
5. 当前分类器/readout仍有较大可优化空间。

## 下一阶段高精度优化顺序
1. **保持杨昊东主链不变**，先搜索GCN hidden dimension、1/2/3层、残差/跳连、LayerNorm、Dropout与node-aware readout；
2. 在训练/验证集上比较A0物理图、审计后的A0+A1任务子图、统计相关图，测试集不参与图选择；
3. 优化Masked residual pretraining：mask比例、连续时间块mask、节点mask、decoder结构、预训练轮次；
4. 比较“冻结encoder”和“低学习率fine-tune encoder”，并重点检查5%/10%/20%标签场景；
5. 使用class-balanced sampling / label smoothing等训练策略提高边界类稳定性；
6. 在不改变固定test的前提下，重新审计半物理故障场景的物理严重度范围，使训练集覆盖合理的轻/中/重故障，而不是通过测试集反馈调整幅值；
7. 最终只在所有结构/超参数通过validation冻结后运行test并形成论文最终表格。
