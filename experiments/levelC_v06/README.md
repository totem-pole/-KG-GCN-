# Level-C VHP KG-GCN Experiment v06

> 总体研究对象仍为燃煤机组汽轮机系统；本目录仅对应论文算例中的VHP代表性故障诊断实验。

## 1. 目的

v04已经证明`KG-GCN > CNN > AE`，但0.8958左右的Macro-F1不足以作为最终论文结果。v05/v06不改变真实健康残差背景、24个DCS节点、自然日互斥split和故障空间/时间签名，只区分故障可观测强度，用于把“典型故障分类”与“弱故障鲁棒性”分开。

- v03：0.5--1.3 sigma，弱/中等故障鲁棒性；
- v05：1.0--2.0 sigma，中等典型故障；
- v06：1.5--2.5 sigma，发展期/清晰可观测故障。

这里的sigma为训练健康残差标准差单位。所有版本均使用相同健康DCS背景、相同日期split、相同故障节点集合和相同step/ramp/sigmoid时间轮廓。

## 2. 固定数据协议

- 健康背景：2024-06真实DCS实测值减GRU健康模型预测值；
- 24个VHP最终状态测点；
- 窗口长度：60 min；
- 类别：F0正常、F1 VHP通流侵蚀/SPE、F2 一级抽汽逆止门后管路泄漏、F3 VHP汽封泄漏；
- Train/Val/Test = 1712/556/560，四类平衡；
- 按自然日互斥切分，窗口不得跨日或跨split；
- KG邻接：沿用v04冻结的A0本机有序传感器拓扑，故障签名不参与邻接构造。

## 5. 模型结构

当前候选仍属于KG-GCN技术路线，不引入TCN/GRU/Transformer主干。输入为`24 x 60`残差窗口：

1. Local path：每个节点自身60点残差通过线性特征映射；
2. Graph path：残差首先按归一化KG邻接矩阵聚合，再进行线性特征映射；
3. 两路节点特征拼接并LayerNorm；
4. 保留24个固定节点身份后展平；
5. 全连接分类层输出4类Softmax结果。

该设计可视为GCN中的skip/local-information preservation，用于避免图传播导致局部故障特征被过度平滑。

## 6. h64审计

hidden=64的一层模型在seed123验证集Macro-F1为0.9659，略高于h32的0.9622，但独立测试Macro-F1仅0.9500。因此不依据test反向选择h64，当前仍保留结构更简单的h32作为主候选，并继续做多seed/预训练优化。

## 7. 与杨昊东路线的关系

最终论文方法链保持：运行生产资料构建KG -> 健康模型残差窗口 -> 残差映射KG参数节点 -> GCN逐层聚合 -> Masked pretraining -> 少量故障标签分类 -> Accuracy/Precision/Recall/F1/混淆矩阵。v05/v06属于第五章故障数据和KG-GCN分类器的开发阶段，不改变第四章主技术路线。

## 8. 下一步

1. 在不改变split和节点签名的前提下继续提升KG-GCN稳定精度；
2. 完成CNN/AE在最终主数据协议上的公平对比；
3. 重新实现更贴近论文路线的masked reconstruction pretraining，并验证scratch vs pretrain；
4. 在主故障算例之外保留v03/v05作为严重度鲁棒性实验；
5. 每个seed单独运行并立即落盘，避免单次任务超时。
